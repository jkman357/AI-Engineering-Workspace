# v0.0.4rc01 POC

## Purpose

Move from a fixed 4-browser + 2-file layout to a dynamic pane workspace.

## Changes

- File panes moved to the left side.
- Browser panes remain on the right side.
- `+ Files` and `+ Browser` dynamically add panes.
- Every pane has a small `×` in its upper-right corner.
- Browser pane `×` removes the pane. Workspace-launched Firefox windows owned by the pane are closed; Dock Existing windows are restored by the existing ownership rules.
- File pane `×` removes only that file pane.
- Browser POC supports up to 8 panes (2×4 roadmap target).
- File POC supports up to 4 panes.
- File list uses Windows Shell small icons for folders and files, including EXE/TXT/ZIP/LNK and other registered types.
- Default File panes: Downloads and Desktop.
- Default Browser URL: Google.

## Acceptance checks

1. Build with `build.cmd`.
2. Run with `run.cmd`.
3. Confirm Files appear on the left and Browsers on the right.
4. Confirm file/folder icons resemble Windows Explorer type icons.
5. Add and close File panes repeatedly.
6. Add and close Browser panes repeatedly.
7. Confirm four default browser panes can all Launch + Dock Firefox.
8. Close one Browser pane with `×`; other panes must remain usable.
9. Confirm Workspace shutdown still gracefully closes Workspace-launched Firefox windows.
10. Confirm drag from File pane toward a docked browser still starts Windows FileDrop.
