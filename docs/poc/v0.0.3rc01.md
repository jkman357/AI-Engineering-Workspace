# v0.0.3rc01 POC

## Objective

Integrate the first usable File Manager surface without disturbing the validated 2×2 Firefox docking baseline.

## Acceptance points

- Four browser tiles still dock independent Firefox HWNDs.
- Browser default URL is Google for every tile.
- Tile-level `×` closes only the exact Firefox HWND docked in that tile.
- Two independent File panes appear on the right.
- File panes support path navigation, parent, refresh and folder double-click.
- Standard Windows file drag starts from a selected file.
- Closing Workspace preserves rc02 browser lifecycle behavior.

## Known POC boundary

Starting a `FileDrop` drag from WPF is implemented, but whether a particular docked webpage accepts the drop is a runtime interoperability test. No browser DOM automation or API is used.
