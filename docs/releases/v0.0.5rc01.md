# AI Engineering Workspace v0.0.5rc01

## Release theme

**Unified Dynamic Pane + Endpoint Identity**

## Goals

1. File and Browser panes can be resized independently.
2. File and Browser panes can move and exchange positions on one workspace surface.
3. File display indices are limited to 1..4 and Browser display indices to 1..8, with smallest-free-index reuse after deletion.
4. `Show IDs` exposes `F1..F4` and `B1..B8` routing aliases as preparation for future context/message routing.

## Identity contract

- `PaneId` is a GUID and is the future machine-routing identity.
- `F1..F4` / `B1..B8` are human-readable aliases.
- Moving a pane does not change PaneId or alias.
- Deleting a pane frees its display index for reuse by a future pane.
- Reusing a display alias creates a new PaneId; it is not the same endpoint instance as the deleted pane.

## Layout POC

The previous fixed left/right area split is removed. Both pane types share one scrollable Canvas surface.

- Drag `⋮⋮` to move a pane.
- Drag `◢` to resize a pane.
- Dropping a pane so it overlaps another pane swaps the two positions.
- Dropping into an unoccupied position keeps the new free position.

This is a POC layout engine. Persisted geometry, snap zones, and Workspace Save/Load are intentionally deferred.

## Security/privacy statement

The application does not store, collect, persist, or manage user account credentials or passwords. Authentication state remains managed by Firefox/browser profiles.

## Build gate

Use `build.cmd`. The Windows/.NET 10 command-line build result is the acceptance gate for this RC.
