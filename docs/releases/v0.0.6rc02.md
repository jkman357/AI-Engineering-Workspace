# v0.0.6rc02 — License / Disclaimer Boundary Clarification

This release retains the application behavior of v0.0.6rc01. No functional behavior change is intended.

## Repository/documentation changes

- Keep the standard MIT `LICENSE` text unchanged.
- Reframe the README Disclaimer as practical engineering risk guidance rather than an additional software-use restriction.
- State explicitly that the README Disclaimer does not restrict or modify permissions granted under the MIT License.
- Clarify that users or adopting organizations must independently evaluate production, enterprise, medical, safety-critical, regulated, and other high-assurance deployments for security, privacy, reliability, validation, regulatory, compliance, and operational risk.
- State that the project has not been independently validated, certified, or qualified for a specific regulated or safety-critical application.
- Keep credential handling separate from the Disclaimer: AI Engineering Workspace does not store, collect, persist, or manage account credentials or passwords, and does not intentionally access or maintain browser password-manager data.

## Functional baseline retained

The following v0.0.6rc01 behavior remains unchanged:

- maximized startup and workspace auto-fit
- dynamic File/Browser panes and endpoint identity
- Browser URL + Enter navigation
- Firefox pane auto-fit without F11 full-screen
- toolbar icons + tooltips
- Explorer-style File pane context menu and keyboard shortcuts
- Firefox HWND lifecycle ownership protections
- command-line build/run and diagnostic logging
