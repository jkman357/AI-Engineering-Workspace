# AI Engineering Workspace v0.0.6rc04

## Scope

`v0.0.6rc04` continues the active `v0.0.6` RC line. It is a focused Browser input/focus and toolbar UX correction based on real-machine testing.

## Changes

- release WPF URL-field keyboard focus before transferring input to a docked Firefox HWND;
- add best-effort focus recovery toward Firefox web content after Workspace-driven URL navigation;
- enumerate Firefox child HWNDs and prefer visible Mozilla compositor/content surfaces when available;
- bridge WPF focus/tab entry into the HwndHost toward Firefox content;
- retain `Focus` as an explicit recovery/diagnostic action;
- add focus evidence to runtime logs (root/target HWND, PID/thread, foreground/focus HWNDs, AttachThreadInput status);
- replace Browser Launch + Dock, Dock Existing, Focus, and Detach text buttons with compact icons and tooltips.

## Acceptance focus

The primary rc04 gate is keyboard input inside the actual web page:

1. Dock Firefox.
2. Open ChatGPT or another page with a text field.
3. Click the web-page input.
4. Type normally without pressing the Workspace Focus command first.
5. Text should enter the page rather than remain trapped in the Firefox address bar.
6. Repeat after Workspace URL + Enter navigation.

If the gate fails, attach the runtime log so the selected Firefox content HWND and focus/thread evidence can be reviewed.

## Version status

RC only. `v0.0.6` is not frozen.
