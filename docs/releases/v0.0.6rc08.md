# AI Engineering Workspace v0.0.6rc08

## Scope

Auto-Fit Completion + Native HWND Repaint + Git Status UI.

## Changes

- Single remaining pane in Auto Fit fills the visible Workspace from `(0,0)` automatically.
- Auto Fit surface size is derived from the current viewport rather than stale Free Layout canvas bounds.
- Firefox child HWND geometry commits suppress intermediate redraw, then invalidate browser, host, and WPF parent HWNDs on the final repaint pass.
- File panes detect child directories that are Git repository roots and display a visible status badge without requiring navigation into the repository first.
- Repository badges summarize dirty state (`!`, `+`, `−`) or show `✓` for clean repositories.
- Existing in-repository file/folder Git status remains read-only and uses local `git.exe`.

## Validation focus

1. Delete panes until only one remains while Auto Fit is enabled; it must fill the Workspace automatically.
2. Resize/maximize/restore a docked Firefox pane repeatedly; check exposed regions for stale pixels.
3. Browse Desktop or another parent folder containing Git repositories; repository folders must show Git badges.
4. Enter a repository and confirm file/folder status badges still reflect working-tree state.
