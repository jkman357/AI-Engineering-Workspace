# AI Engineering Workspace v0.0.6rc15

## Scope

Browser maximize / restore focus recovery. This continues the active v0.0.6 RC line and is not a frozen release.

## Real-machine finding from rc14

Normal Auto Fit Browser operation was observed working across B1-B8 for English/number input and Zhuyin composition. The remaining deterministic failure occurred after entering the Browser Workspace maximize mode: both ordinary ASCII input and Zhuyin could stop reaching Firefox.

This separates the defect from the rc14 IME investigation. The maximize button is WPF-owned chrome, so clicking it moves keyboard focus to WPF while the pane also undergoes visibility, geometry, native HWND resize, and repaint transitions.

## rc15 change

- Keep the rc14 `FirefoxInputCoordinator` transactional root focus path.
- Do not add another persistent `AttachThreadInput` bridge.
- After Browser maximize geometry is complete, defer recovery until `DispatcherPriority.ContextIdle`.
- Refit and final-repaint the docked Firefox HWND before the focus handoff.
- Clear WPF keyboard focus before returning root-HWND focus to Firefox.
- Apply the same deferred recovery after an explicit restore from the Browser maximize/restore button.
- Other calls that merely restore a maximized pane as a side effect of Add / layout / save behavior do not automatically steal focus back to Firefox.
- Preserve rc14 HKL / `GetGUIThreadInfo` / IME diagnostics as read-only evidence.
- Do not synthesize `WM_IME_COMPOSITION`, activate a keyboard layout, or force Firefox internal child-HWND focus.

## Windows manual PASS gate

Without pressing the `⌖` Focus button:

1. B1 normal: English/number input PASS; Zhuyin input PASS.
2. B1 maximize (`□`): English/number input PASS; Zhuyin input PASS.
3. B1 restore (`❐`): English/number input PASS; Zhuyin input PASS.
4. B3 maximize: English/number input PASS; Zhuyin input PASS.
5. B3 restore: English/number input PASS; Zhuyin input PASS.
6. B1 maximize -> restore -> B6 maximize -> restore -> B2 input remains functional.
7. Capture `logs\runtime\AIEngineeringWorkspace_*.log` if any transition fails; the runtime log should include `MaximizeCompleted` / `RestoreCompleted` focus-recovery reasons and the retained HKL / GuiFocus evidence.
