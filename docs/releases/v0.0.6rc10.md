# AI Engineering Workspace v0.0.6rc10

## Scope

Workspace Project Save/Load + Endpoint UI cleanup. This remains an RC in the active v0.0.6 line.

## Added

- New / Open / Save / Save As Workspace-project commands.
- `.aew` JSON project format with format versioning.
- persistence of layout mode, pane type, PaneId, F#/B# display index, X/Y, width/height, File-pane folder path, Show IDs state, and main-window size/state.
- missing File-path fallback to Desktop during load.
- unsaved-change marker and save/discard/cancel prompts.
- permanently visible compact boxed F#/B# aliases.
- optional 64×64 Show IDs endpoint overlays using the existing endpoint color palette.
- Workspace-project and endpoint-badge regression checks.

## Browser persistence boundary

Browser current URL/history/session/credentials are intentionally not stored in `.aew`. Browser panes are reconstructed as layout/routing endpoints only. Launching a restored Browser pane starts Firefox at `https://www.google.com/`.

## Security note

`.aew` files can contain local filesystem paths and layout metadata. They do not intentionally contain credentials, but they should still be reviewed before public sharing.
