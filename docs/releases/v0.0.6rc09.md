# AI Engineering Workspace v0.0.6rc09

## Scope

Review-hardening release for the active v0.0.6 RC line. No new product feature is introduced.

## Fixed review findings

1. Auto Fit layout now respects pane minimum dimensions and scrolls rather than overlapping when the viewport is too small.
2. Git decoration work is background, cancellable, generation-guarded, and snapshot-cached so WPF navigation does not synchronously wait on Git commands.
3. Firefox launch ownership begins inside `FirefoxWindowService`; shutdown/cancellation cleans pending launch candidates created after the recorded pre-launch HWND baseline.
4. Git porcelain rename/copy records keep the current/destination path.
5. Empty Git glyphs collapse the badge overlay.
6. `Directory.Build.props` is the executable version authority; rc09 package/file/informational metadata is `0.0.6-rc09` / `0.0.6.9` / `v0.0.6rc09`.
