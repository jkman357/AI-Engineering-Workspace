# AI Engineering Workspace v0.0.6rc12

## Scope

Browser Keyboard Input + New Workspace Confirmation. This continues the active v0.0.6 RC line and is not a frozen release.

## Changes

- Replace normal Firefox child-HWND focus guessing with a dock-lifetime input-queue bridge between the Workspace UI thread and the Firefox root-window thread.
- Let Firefox own address-bar/page focus transitions after normal mouse clicks.
- Keep the Workspace Focus button as root-HWND recovery only.
- Make New Workspace explicitly confirm every reset, including when no unsaved changes exist.
- Preserve Save / Discard / Cancel handling when the current Workspace is dirty.
- Stamp the executable/build/test metadata as v0.0.6rc12 / FileVersion 0.0.6.12.

## Validation focus

1. Click Firefox address bar and type without pressing Focus first.
2. Click a page input control and type without pressing Focus first.
3. Move keyboard focus to a Workspace control, click back into Firefox, and type again.
4. Press New Workspace repeatedly and verify every invocation produces a confirmation before reset.
5. Create unsaved layout/path changes and verify New Workspace offers Save / Discard / Cancel semantics.
6. Run `build.cmd`, `test.cmd`, and `run.cmd` on the Windows/.NET 10 validation host.
