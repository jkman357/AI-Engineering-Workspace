# AI Engineering Workspace v0.0.6rc20

## Scope

Zero-mutation native Firefox control baseline. This continues the active v0.0.6 RC line and is not a frozen release.

## Real-machine finding from rc19

rc19 removed cross-process `SetParent` embedding and kept Firefox as a native top-level HWND, but real-machine testing still produced this boundary:

- English/number input: PASS;
- Zhuyin/Chinese composition: FAIL;
- runtime evidence showed `SetParentUsed=False`, no persistent input bridge, native top-level foreground/focus, and matching zh-TW HKL;
- therefore `SetParent` is not the only condition affecting the failure.

rc19 still mutated two pieces of Firefox top-level identity: it removed native frame/caption style and assigned the Workspace as the Firefox owner. rc20 removes both variables at once to create a clean control group.

## rc20 zero-mutation rules

```text
WPF Browser pane
    └─ native geometry-anchor HWND
           ↓ GetWindowRect

Firefox original native top-level HWND
    ├─ NO SetParent
    ├─ NO GWL_HWNDPARENT owner reassignment
    ├─ NO GWL_STYLE mutation
    ├─ NO GWL_EXSTYLE mutation
    ├─ NO AttachThreadInput
    ├─ NO root SetFocus
    ├─ NO HKL manipulation / synchronization
    ├─ NO synthetic IME composition
    └─ SetWindowPos(... SWP_NOACTIVATE ...) mirrors pane geometry only
```

The native Firefox title bar and frame remain visible by design. rc20 is an isolation experiment, not the intended final visual presentation.

The Workspace may still use ShowWindow to hide/reshow pseudo-docked Firefox with Workspace visibility/minimize state. On detach it restores the original window placement; it does not need to restore owner/style because they were never changed.

## Windows manual PASS gate

Do not press `⌖ Focus` during the normal-input gate.

1. Start from a clean Workspace and launch **B1 only**.
2. Confirm Firefox retains its normal native title bar/frame.
3. In the B1 address bar type `abc123` and confirm ordinary English/number input works.
4. Switch to Zhuyin and compose/commit `你好`.
5. Continue typing English/number after switching back.
6. Capture `logs\runtime\AIEngineeringWorkspace_*.log`. Evidence should include `SetParentUsed=False`, `OwnerMutation=False`, `StyleMutation=False`, and no input bridge/root-focus forcing.
7. **If Chinese PASS:** do not immediately expand to B1-B8. The next RC should reintroduce owner and style mutations one at a time to isolate which mutation breaks IME.
8. **If Chinese FAIL:** owner reassignment and style mutation are ruled out. Investigation should move to Firefox window creation/session/TSF behavior rather than adding WPF focus APIs.

Only after B1 English + Zhuyin passes should B2-B4 and then B1-B8 routing/layout tests be run.
