# v0.0.6rc03 — Adaptive Workspace + File Manager UX + Security Hardening

`v0.0.6rc03` continues the active `v0.0.6` RC line.

## Functional changes

- Auto Fit is the default workspace layout mode.
- Remaining panes reflow after add/remove and on viewport resize.
- Manual pane move/resize switches to Free Layout.
- Browser panes can maximize/restore inside the Workspace without entering Firefox F11 monitor full-screen.
- Docked Firefox HWND content continues to fit the Browser pane client region.
- File Manager Name / Type / Size / Modified headers are clickable and toggle ascending/descending sorting.
- Existing Explorer-like file operations remain available.

## Security/documentation hardening

- credential wording is scoped to design intent rather than an absolute promise;
- Firefox profile/session state is explicitly documented as an external trust boundary;
- runtime log location, retention, rotation, disable/configuration, and best-effort redaction behavior are documented;
- privilege wording remains “designed for standard-user execution” because `asInvoker` can inherit an already elevated caller token;
- MIT License permissions remain unchanged and README risk guidance does not add use restrictions.

## Runtime logging defaults

```text
Retention age : 14 days
Max files     : 50
Rotation      : 10 MB/file
Disable       : AIEW_RUNTIME_LOG=0
```

Best-effort sensitive-value redaction is not a guarantee. Review diagnostics before public sharing.
