# AI Engineering Workspace v0.0.6rc11

## Scope

Workspace Project UX + Endpoint Badge Fix. This is an RC continuation of v0.0.6 and does not freeze the release line.

## Changes

- Move Show IDs 64×64 endpoint badges into WPF-owned pane header chrome.
- Highlight the Browser/File pane frame using its endpoint color while Show IDs is active.
- Remove visible `+<source-revision>` metadata from the application title/version label while retaining single-source version metadata.
- Make New Workspace a repeatable deterministic reset with explicit timestamped/reset-sequence status feedback.
- Preserve rc10 `.aew` project save/load behavior and security/privacy boundaries.

## Validation focus

1. Enable Show IDs with a docked Firefox window: B1-B8 large badges must remain visible and must not be hidden by Firefox.
2. File and Browser panes should both show endpoint-colored frame emphasis while Show IDs is enabled.
3. Title/version text must show `v0.0.6rc11` without `+<commit-hash>`.
4. Press New Workspace repeatedly: every press must reset to the default workspace and update the status feedback.
5. Run `build.cmd`, `test.cmd`, and `run.cmd` on the Windows/.NET 10 validation host.
