# AI Engineering Workspace v0.0.6rc06

Status: Release Candidate — **not frozen**

## Theme

Native Windows Shell integration + Git working-tree visibility + reliable Free Layout resize hit testing.

## Changes

- Eight-direction pane resize uses explicit transparent hit surfaces and larger edge/corner targets.
- File-pane right-click uses Windows Shell `IContextMenu` instead of a Workspace-emulated menu.
- Dynamic Shell menu messages are forwarded so registered extensions can populate submenus.
- 7-Zip, comparison tools, TortoiseGit, and other installed Explorer integrations can appear when registered on the workstation.
- Git working-tree badges are displayed using read-only local `git.exe` status probes.
- Workspace keyboard file actions remain as fallback operations.
- `SECURITY.md` documents Shell extensions as a third-party trust boundary.

## Validation focus

1. Build with `build.cmd`.
2. Verify edge/corner pane resize in Free Layout.
3. Verify a docked Firefox HWND follows Browser pane resize.
4. Right-click ZIP files and verify installed 7-Zip Shell commands.
5. Right-click Git working-tree items and verify installed TortoiseGit commands.
6. Verify Git status badges for clean/modified/untracked items.
7. Re-test Browser focus, URL navigation, Detach, Auto Fit, and Workspace shutdown behavior.
